How the imprest system works

Each branch spends from a float. Money is released into it through the normal Payment flow, expenses draw it down, and you get an alert when it runs low.

The flow
  1. Set the float — an accountant/MDS sets each account's standard float and the low-alert threshold (default 20%).
  2. Fund it — a branch manager taps Request Top-Up. That raises a payment request; once MDS approves and it's marked disbursed, the amount credits the float.
  3. Spend it — cashiers and branch managers log expenses against the float. Balance = released − spent, updated live.
  4. Watch the balance — when it drops to the threshold, the account flags red on the dashboard: time to top up.
Who does what
  • Cashier — records expenses for their branch.
  • Branch Manager — records expenses, raises top-up requests, edits/deletes their branch's expenses.
  • Accountant / MDS — all branches, set floats, import/export.

Every action is logged (who, when, how much) in each account's Activity Log.

Import / Export

Expenses export as a Zoho Books-format CSV (respecting your filters), and you can import a Zoho export back in — rows match to accounts by Paid Through and are de-duplicated on Expense Reference ID.
